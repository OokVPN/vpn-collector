OokVPN

Бесплатная подписка для Happ с автоматически собираемыми VPN-конфигурациями.

Возможности

- 🆓 Полностью бесплатно
- 🔄 Автоматическое обновление списка серверов
- ⚡ Автоматическая проверка работоспособности узлов
- 🌍 Серверы из разных стран
- 🔐 VLESS
- 🔐 VMess
- 🔐 Trojan
- 🔐 Shadowsocks
- 🔐 Hysteria2
- 🤖 Автоматический профиль с рабочими узлами
- 📊 Поддержка информации о трафике через "subscription-userinfo"
- ♾️ Без установленного лимита трафика
- ☁️ Раздача подписки через Vercel CDN

GitHub Actions автоматически запускает обновление, собирает новые конфигурации и проверяет их перед публикацией.

Подписка Happ

Добавьте URL:

https://YOUR-VERCEL-DOMAIN/subscription.json

После добавления Happ получает:

- название подписки: OokVPN
- трафик: 0 / ∞
- без заданного срока окончания

Автоматическое обновление

Workflow GitHub Actions запускается:

- вручную через "workflow_dispatch"
- автоматически каждые 30 минут

При обновлении проект:

1. получает конфигурации из источников;
2. удаляет дубликаты;
3. проверяет доступность серверов;
4. оставляет рабочие узлы;
5. определяет страны серверов;
6. создаёт профили;
7. обновляет "subscription.json";
8. публикует изменения через Vercel.

Важно

Проект использует публично доступные конфигурации. Работоспособность бесплатных серверов может изменяться в любой момент, поэтому наличие конкретного сервера в источнике не гарантирует его постоянную доступность.

Не используйте неизвестные VPN-конфигурации для передачи чувствительных данных без понимания того, кому принадлежит сервер.

Лицензия

Проект предназначен для образовательного и личного использования.
